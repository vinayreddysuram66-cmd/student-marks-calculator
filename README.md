Student Marks Calculator in C

A beginner-friendly C programming project that calculates a student's total marks, average, and grade.

Features

- Accepts the student's name
- Takes marks for three subjects
- Validates marks between 0 and 100
- Calculates total marks and average
- Assigns a grade based on the average

Technologies Used

- C Programming Language

How to Run

Compile the program using GCC:

gcc main.c -o marks

Run it:

./marks

On Windows, run "marks.exe" after compiling.

Purpose

This project was created to practise C programming, loops, conditional statements, input validation, and basic calculations.
